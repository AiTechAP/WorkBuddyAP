## 二、课程介绍

WorkBuddy 是由腾讯推出的全场景 AI 办公工作台。用户通过自然语言下达任务命令，WorkBuddy 能够自动拆解、自主规划、调用工具完成多步骤的办公任务，最终直接交付成品文件。

本课程从 WorkBuddy 基础入手，系统讲解其核心能力，并重点分享在教育场景下的应用实践。
